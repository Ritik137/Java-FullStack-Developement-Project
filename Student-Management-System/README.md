# 🎓 Student Management System

A modern **Student Management System** built using **JSP, Servlets, and Bootstrap 5** with a clean UI and smooth animations.

---

## 🚀 Features

- ➕ Add new students  
- ✏️ Edit student details  
- 🗑️ Delete students  
- 🔍 Search & filter students  
- 📊 Dashboard with stats  
- 🎨 Modern animated UI (Glassmorphism + AOS)

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript  
- **Backend:** Java (JSP & Servlets)  
- **Database:** MySQL *(or your DB)*  
- **Server:** Apache Tomcat
